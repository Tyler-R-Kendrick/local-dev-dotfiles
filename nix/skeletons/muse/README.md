# Muse Code — Meta terminal coding agent (helper-installed)

Install / refresh:

```bash
just muse
# or: bash scripts/agents/install-muse.sh
```

Login (interactive, secrets not in git):

```bash
muse login
```

Credentials: `~/.config/muse/auth.json` — optionally mapped in the local
`~/.config/dev/secrets-map.md` file.
